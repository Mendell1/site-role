# Rolê — Checklist V25.5 de entrega

Objetivo: validar a V25 como produto integrado antes de congelar uma nova versão estável. A V25.5 não adiciona recursos grandes; ela verifica regressões, UX, mobile e os fluxos criados da V25.1 à V25.4.

## 1. Visitante

- [ ] Abrir o mural sem login e carregar eventos futuros.
- [ ] Busca comum continua funcionando por nome/descrição.
- [ ] Busca inteligente aceita uma frase natural e mostra o que foi interpretado.
- [ ] Categorias, Hoje, Fim de semana, Próximos 7 dias e Grátis continuam funcionando.
- [ ] Mapa e calendário abrem sem quebrar o mural.
- [ ] Detalhe do evento abre sem piscar e sem cartão preto.
- [ ] Visitante vê a área Participação e recebe convite para entrar ao tentar participar.
- [ ] Perfil público do organizador abre corretamente.
- [ ] Botões de fechar modais funcionam com clique e tecla Escape.

## 2. Usuário logado

- [ ] Cadastro/login e Google OAuth continuam funcionando.
- [ ] Favoritar e Tenho interesse continuam separados de Quero participar.
- [ ] Quero participar confirma vaga quando existe capacidade.
- [ ] Evento lotado coloca usuário na lista de espera e mostra posição.
- [ ] Cancelar participação libera a vaga corretamente.
- [ ] Minhas inscrições aparece no perfil sem duplicar abas.
- [ ] Meu ingresso abre com QR visível e código manual abaixo.
- [ ] QR não contém nome/e-mail do participante.
- [ ] Usuário consegue seguir/deixar de seguir organizador.
- [ ] Alertas podem ser criados, pausados, reativados e excluídos.
- [ ] Aba Para você carrega recomendações para usuário logado.
- [ ] Push só pede permissão quando o usuário clica em Ativar neste aparelho.
- [ ] Perfil não apresenta componentes duplicados após navegar entre abas.

## 3. Capacidade e lista de espera

- [ ] Criar evento com 2 vagas.
- [ ] Usuário A entra: 1/2.
- [ ] Usuário B entra: 2/2.
- [ ] Usuário C entra na fila: posição 1.
- [ ] Usuário A cancela.
- [ ] Usuário C é promovido automaticamente.
- [ ] Usuário C recebe notificação da promoção.
- [ ] Nenhum cenário ultrapassa a capacidade definida.

## 4. Organizador / presencial

- [ ] Organizador vê lista de inscritos e fila.
- [ ] Check-in por QR abre câmera em navegador compatível.
- [ ] Código manual funciona quando BarcodeDetector não está disponível.
- [ ] Ingresso de outro evento é recusado.
- [ ] Segundo scan do mesmo ingresso é identificado como já utilizado.
- [ ] Painel presencial atualiza inscritos, presentes, fila e taxa de comparecimento.
- [ ] Desfazer check-in funciona e atualiza métricas.
- [ ] Participante não consegue cancelar inscrição após check-in.

## 5. Administração

- [ ] Painel administrativo abre apenas para admin.
- [ ] Denúncias, Eventos, Usuários e Auditoria continuam funcionando.
- [ ] Área de verificação de organizadores aparece uma única vez.
- [ ] Conceder selo registra verificação e atualiza perfil público.
- [ ] Remover selo atualiza perfil público.
- [ ] Nenhum botão administrativo aparece duplicado.

## 6. PWA e Push

- [ ] Manifesto é reconhecido pelo navegador.
- [ ] Ícone 192 e 512 carregam.
- [ ] Rolê pode ser instalado como aplicativo quando o navegador oferece suporte.
- [ ] Fechar o convite de instalação impede que ele reapareça imediatamente.
- [ ] Abrir o app instalado usa modo standalone.
- [ ] Service Worker atualizado remove caches antigos da V25.4.
- [ ] Sem internet, o shell já visitado abre e informa estado offline.
- [ ] Respostas do Supabase não são armazenadas no cache do Service Worker.
- [ ] Ativar Push registra somente o aparelho do usuário logado.
- [ ] Uma notificação do Rolê chega com o site fechado.
- [ ] Tocar na notificação abre o evento/perfil correspondente.

## 7. Mobile / responsividade

Testar pelo menos em 360x800, 390x844 e 768x1024.

- [ ] Nenhum conteúdo gera rolagem horizontal involuntária.
- [ ] Menu mobile continua acessível.
- [ ] Modal de detalhe cabe na altura da tela e rola internamente.
- [ ] Modal Meu ingresso mostra QR inteiro.
- [ ] Scanner, painel e lista de participantes cabem na tela.
- [ ] Botões novos têm área de toque confortável.
- [ ] Chips da busca inteligente quebram linha corretamente.
- [ ] Banner da PWA não fica escondido pela área segura do aparelho.

## 8. Acessibilidade e acabamento

- [ ] Tab navega pelos principais controles.
- [ ] Foco é visível nos recursos V25.
- [ ] Ao abrir modal, foco vai para o modal/fechar.
- [ ] Escape fecha o modal superior.
- [ ] Avisos possuem região aria-live.
- [ ] Com prefers-reduced-motion, animações/transições são reduzidas.
- [ ] Abrir/fechar vários modais não deixa o body travado.

## 9. Regressão final

- [ ] Console sem erros JavaScript durante o fluxo principal.
- [ ] CI: sintaxe JavaScript aprovada.
- [ ] CI: smoke.py aprovado.
- [ ] CI: v25_2_static.py aprovado.
- [ ] CI: v25_5_static.py aprovado.
- [ ] V24 permanece inalterada em v24-stable.
- [ ] Preview V25 corresponde ao commit atual de v25-experimental.

Quando todos os itens críticos estiverem aprovados, criar uma tag/branch estável da V25 antes de iniciar novas funcionalidades.
